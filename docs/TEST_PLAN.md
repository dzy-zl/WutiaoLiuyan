# 真机验收清单

## 安装与主题
- Android 10、Android 13+、Android 17 各测试一次。
- 跟随系统/浅色/夜间模式切换正常。

## 导入
- 相册单图、多图；相机竖拍；微信“分享到五条六眼”；网页纯文字分享。
- 多图移除后临时文件不残留。

## AI
- 正确 Key、错误 Key、余额不足、限流、断网。
- 连续对话与独立分析差异。
- 重复截图、时间变更、相对日期、金额、联系人、重复任务。
- DeepSeek 失败后 OCR 降级。

## 任务
- 缺少日期不可保存；日期/时间选择器；项目/分类；高/中/低优先级。
- Inbox/今日/计划/进行中/已完成筛选。
- 重复任务完成后只生成一条下一周期任务。
- 删除、撤销、30 天回收站策略、来源截图清理选项。

## 提醒
- Android 13+ 首次保存提醒任务时申请通知权限。
- 有时间任务提前提醒；仅日期任务前一天 20:00。
- 通知完成、延期 30 分钟；重启后恢复。

## Widget 与导出
- 两个 Widget 更新数量。
- Markdown、CSV、ZIP 可分享；ZIP 中无 API Key。
